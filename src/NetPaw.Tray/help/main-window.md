# Main window

The tray is the fast path; the main window is the same thing with room to breathe. Open it from the
tray menu (**Open NetPaw window…**), by double-clicking the tray icon, with `NetPaw.exe --main`, or by
typing `window` in the quick panel. *Settings → Tray click opens* makes a single click open it instead
of the quick panel. Closing the window hides it; the tray keeps running (*Exit* lives in the tray menu).

- **Overview** — the info card (same rows and advice as `Ctrl+Alt+I`) plus DHCP, Renew, Reset,
  Re-check and a reach box (`192.168.88.1`, `10.0.0.0/16`, `nas:22`).
- **Profiles** — every profile with its configuration, adapter, hotkey and *current* / *managed* badge.
  Double-click or *Apply* applies (verified, like everywhere else). *Edit…* opens the editor.
- **Tools** — switch port (LLDP/CDP), route table, find routers, trace route and port check with their
  output right there, Wake-on-LAN, scan, diagnostics export.
- **Map** — the network map (neighbours, find routers, switch, routes) inside the window.
- **Log** — the last 200 lines of `netpaw.log` or the incident log; *Open config folder*.

The window remembers its size, position and page. F1 opens the help topic for the current page; Esc hides.
